# Documentation

Generated documentation serves project developers. It deliberately includes exported symbols from internal application modules and helpers, not only component barrels. Native TypeDoc discovery owns input selection in [`docs/astro.config.ts`](../astro.config.ts); no per-file registration or barrel promotion is required. Native documentation commands are defined in [`package.json`](../../package.json).

These compact project references are normative. Human guides explain and illustrate them without maintaining a second rule catalogue. Link portal guides to the corresponding repository-source reference, since these files are outside the portal content collection.

Use current official library documentation for library-specific implementation guidance rather than caching upstream API snippets. Machine-enforced settings remain in executable configuration. Original explanatory text follows [Prose](prose.md).
