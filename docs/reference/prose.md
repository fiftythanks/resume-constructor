# Prose

- Write original prose in standard British English, using -ise and -isation rather than -ize and -ization where both forms are valid.
- Write lists of three or more items without an Oxford (serial) comma: "A, B and C" or "A, B or C". Rephrase ambiguous lists. Retain commas that serve other grammatical functions.
- Use double quotation marks for primary quotations.
- Use spaced em rules for parenthetical breaks (word — word) and unspaced en rules for ranges (1–10).
- Put spaces around a slash separating multi-word phrases; leave it unspaced between single words.
- Format code identifiers, paths and commands as code when mentioning them in prose.
- When applying these conventions, preserve verbatim quotations, proper names and literal code, paths and URLs.
